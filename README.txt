《到家了嗎》四幕可玩試作 v0.1

開啟方式：
1. 想快速試玩：使用「到家了嗎_單檔試玩.html」，所有角色照片已包在檔案裡。
2. 若手機不允許直接執行下載的 HTML：將「到家了嗎_四幕試作.zip」解壓縮，整個資料夾上傳到自己的 Netlify Drop／靜態網站空間，再用網址試玩。
3. 在電腦上也可以解壓後開啟 index.html。

玩法：點開每幕指定 App 看舊紀錄、對日期、選擇回覆。全部四幕與兩個結局均可玩。下方「線索」可查看已確認資訊，「重來」會清除進度。進度只存在你使用的瀏覽器本機。

這是用來邊玩邊改故事的濃縮初版：約 15–30 分鐘，並非最終預計的 2–3 小時。照片欄位只在瀏覽器本機預覽，不會上傳；遊戲不連外，也不使用 AI 辨識。傳照片後收到的是預先寫好的通用回覆。若關閉或重整頁面，選過的照片本身不會留在進度裡。

目前使用的角色形象是先前通過的生活感版本；人名「小芸／予安」和團體名稱「微光之家」是暫名，可在後續改稿。故事含心理操控與自殺者遺留紀錄，沒有自殺方法與血腥畫面。
